Bring your apps together.

Import a snapshot, pull metrics from your API, or send updates from your automations.

JSON import

Upload daily metrics from any app. Validated before saving; replaces the current dataset.

⌘

REST API

Connect an HTTPS JSON endpoint. Configure credentials and field mappings in your server’s .env file.

Setup instructions

Copy .env.example to .env, add a CONNECTORS entry, and restart the server. Use rowsPath for nested arrays and mapping for custom field names. Sync imports a full snapshot; combine app data upstream for a unified dataset.

ϟ

Automation webhook

Send daily metrics from Zapier, Make, n8n, or your own application.

POST /api/ingest
Setup instructions

Set INGEST_TOKEN in .env. Send a JSON array with Authorization: Bearer YOUR_TOKEN. Each request replaces the full dataset. Remote automation requires an authenticated HTTPS deployment; this app starts locally.

One simple data format

One row per day and source. Revenue is in USD; customers means new customers for that day. Use the same currency across sources.

[{"date":"2026-09-11","source":"Online store","revenue":2450.50,"orders":32,"customers":18}]

Existing data stays intact if validation or sync fails. Secrets are never sent to the browser.
